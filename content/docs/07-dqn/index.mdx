## 2. 从查表到参数化函数近似：$\hat{v}(s, \mathbf{w})$

在连续状态空间里，哪怕每走一步都把实数坐标精确记下来，几乎**永远不会两次落到完全相同的浮点坐标上**。因此我们必须放弃查表，改用一个参数向量 $\mathbf{w} \in \mathbb{R}^d$（$d \ll |\mathcal{S}|$）构建**参数化价值函数** $\hat{v}(s, \mathbf{w}) \approx v_\pi(s)$。

### 均方价值误差（Mean Squared Value Error, $\overline{\text{VE}}$）

我们无法在所有无穷个状态上同时做到 0 误差，只能按策略访问状态分布 $\mu(s)$ 加权最小化误差：

$$
\overline{\text{VE}}(\mathbf{w}) \;\doteq\; \sum_{s \in \mathcal{S}} \mu(s)\Big[\, v_\pi(s) - \hat{v}(s, \mathbf{w}) \,\Big]^2
$$

对其做随机梯度下降（SGD），一步更新规则为：

$$
\mathbf{w}_{t+1} = \mathbf{w}_t + \alpha\Big[\, U_t - \hat{v}(S_t, \mathbf{w}_t) \,\Big]\, \nabla_{\mathbf{w}} \hat{v}(S_t, \mathbf{w}_t)
$$

- 当目标 $U_t = G_t$（**梯度蒙特卡洛**）时，$G_t$ 是真值 $v_\pi(S_t)$ 的无偏估计且不依赖 $\mathbf{w}_t$，这是货真价实的 SGD；
- 当目标 $U_t = R_{t+1} + \gamma \hat{v}(S_{t+1}, \mathbf{w}_t)$（**半梯度 TD(0)**）时，目标 $U_t$ 自己也依赖参数 $\mathbf{w}_t$，但求导时我们故意把它当常数不求导（只取了一半梯度！），因此得名**半梯度方法（Semi-Gradient Method）**。

## 3. 线性近似与瓦片编码（Tile Coding）

最稳健且拥有收敛保证的参数化形式是**线性价值函数**：先构造特征向量 $\mathbf{x}(s) \in \mathbb{R}^d$，令 $\hat{v}(s, \mathbf{w}) = \mathbf{w}^\top \mathbf{x}(s)$（此时梯度极简：$\nabla_{\mathbf{w}} \hat{v}(s, \mathbf{w}) = \mathbf{x}(s)$）。

在山地车这类低维连续控制中，**瓦片编码（Tile Coding）**效果奇佳：把 2D 相空间 $(x, v)$ 盖上多层彼此微微错位的粗网格（称为 Tilings）。任意连续状态点在每一层刚好激活 1 块瓦片，于是相近的状态共享大部分激活瓦片（**局部泛化**），同时多层错位叠加又提供了极高的有效分辨率！

## 4. 深度强化学习的头号梦魇：致命三元组（The Deadly Triad）

如果线性半梯度 TD 在策略下很稳，为什么把表格 Q-learning 直接换成深度神经网络，几乎 100% 当场训练崩溃、Q 值飙到 $10^{30}$？

Sutton & Barto 总结了强化学习中最著名的警示——**致命三元组（Deadly Triad）**：只要以下三个要素**同时出现**，价值函数估计就有**指数发散**的风险（哪怕是最简单的线性网络！）：

1. **函数近似（Function Approximation）**：不同状态共享同一套权重 $\mathbf{w}$，更新一个状态会连带改变其他状态的预测；
2. **自举（Bootstrapping）**：用网络自己的估计 $\gamma \hat{v}(S', \mathbf{w})$ 构造更新目标（TD / Q-learning）；
3. **离策略训练（Off-Policy Training）**：采样数据分布 $d^b(s)$ 偏离目标策略分布 $d^\pi(s)$。
