## 1. 当矩阵求逆求不动时：把方程变成“赋值号”

在 3.3 节我们看到，当环境模型 $p(s', r \mid s, a)$ 已知时，Bellman 期望方程可以用矩阵求逆 $\mathbf{v}_\pi = (\mathbf{I} - \gamma \mathbf{P}^\pi)^{-1} \mathbf{R}^\pi$ 一次解出。但矩阵求逆复杂度高达 $O(|\mathcal{S}|^3)$：只要状态数达到 $10{,}000$，光求一次逆就需要 $10^{12}$ 次运算。

动态规划（Dynamic Programming, DP）的做法巧妙得多：**把 Bellman 期望方程的等号直接变成迭代更新规则**！任意初始化一张全 0 价值表 $V_0(s) = 0$，反复用上一轮的估计值 $V_k$ 算出下一轮的 $V_{k+1}$：

$$
V_{k+1}(s) \;\leftarrow\; \sum_{a \in \mathcal{A}} \pi(a \mid s) \sum_{s', r} p(s', r \mid s, a)\Big[\, r + \gamma V_k(s') \,\Big], \qquad \forall s \in \mathcal{S}
$$

每一轮完整扫描所有状态后，记录最大变化量 $\Delta_k \doteq \max_{s \in \mathcal{S}} |V_{k+1}(s) - V_k(s)|$，一旦 $\Delta_k < \theta$（如 $10^{-4}$）即停止。

## 2. 严谨证明：为什么随便猜初值都能保证收敛？

定义一个作用在价值向量 $V \in \mathbb{R}^{|\mathcal{S}|}$ 上的 **Bellman 期望算子 $\mathcal{T}^\pi$**：

$$
(\mathcal{T}^\pi V)(s) \doteq \sum_{a} \pi(a\mid s)\sum_{s', r} p(s', r\mid s, a)\big[r + \gamma V(s')\big]
$$

任取两个相差甚远的初始猜测 $U, V \in \mathbb{R}^{|\mathcal{S}|}$，在无穷范数 $\|U - V\|_\infty \doteq \max_s |U(s) - V(s)|$ 下衡量经算子映射一步后的距离：

$$
\begin{aligned}
\big|(\mathcal{T}^\pi U)(s) - (\mathcal{T}^\pi V)(s)\big|
&= \left|\sum_{a}\pi(a\mid s)\sum_{s',r}p(s',r\mid s,a)\,\gamma\big(U(s') - V(s')\big)\right| \\
&\le \gamma \sum_{a}\pi(a\mid s)\sum_{s',r}p(s',r\mid s,a)\,\big|U(s') - V(s')\big| \\
&\le \gamma \sum_{a}\pi(a\mid s)\sum_{s',r}p(s',r\mid s,a)\,\|U - V\|_\infty \\
&= \gamma \|U - V\|_\infty \qquad \Big(\text{因为概率求和恒等于 } 1\Big)
\end{aligned}
$$

对左侧关于所有状态 $s$ 取最大值，即证得 **$\mathcal{T}^\pi$ 是 $\gamma$-压缩映射（$\gamma$-Contraction）**：

$$
\|\mathcal{T}^\pi U - \mathcal{T}^\pi V\|_\infty \le \gamma \|U - V\|_\infty
$$

因为真值 $v_\pi$ 本身就是不动点（$\mathcal{T}^\pi v_\pi = v_\pi$），反复迭代 $k$ 轮后的误差满足：

$$
\|V_k - v_\pi\|_\infty \le \gamma^k \|V_0 - v_\pi\|_\infty \xrightarrow{\;k \to \infty\;} 0
$$

## 4. 同步更新 vs 原地更新（In-Place DP）与 Python 实现

- **同步更新（Two-Array）**：维护旧表 `V_old` 和新表 `V_new`，本轮所有状态都严格读取 `V_old`；
- **原地更新（In-Place / Gauss-Seidel）**：只维护**一张数组 `V`**，刚算出的 `V[s]` 立即被同一轮后面扫描到的邻居状态使用——在实践中不仅省一半内存，收敛速度通常还快 $30\%\sim 50\%$！

```python
import numpy as np

def iterative_policy_evaluation(P, policy, gamma=0.9, theta=1e-5):
    """
    原地迭代策略评估 (In-Place Policy Evaluation)
    P[s][a] = [(prob, next_s, reward, done), ...]
    policy[s][a] = π(a | s)
    """
    n_states = len(P)
    V = np.zeros(n_states, dtype=float)

    while True:
        delta = 0.0
        for s in range(n_states):
            v_old = V[s]
            v_new = 0.0
            for a, pi_sa in enumerate(policy[s]):
                if pi_sa == 0:
                    continue
                for prob, next_s, reward, done in P[s][a]:
                    v_new += pi_sa * prob * (reward + (0.0 if done else gamma * V[next_s]))
            V[s] = v_new
            delta = max(delta, abs(v_old - v_new))
        if delta < theta:
            break
    return V
```
