## 1. 策略改进定理（Policy Improvement Theorem）完整证明

我们已经会算任意策略 $\pi$ 的真实价值 $v_\pi$ 了。现在的问题是：**怎样构造出一个严格比 $\pi$ 更强的新策略 $\pi'$？**

设 $\pi$ 和 $\pi'$ 是任意两个确定性策略。如果对所有状态 $s \in \mathcal{S}$ 都满足：

$$
q_\pi\big(s, \pi'(s)\big) \ge v_\pi(s)
$$

（即：“在任意状态 $s$ 先走一步新策略 $\pi'(s)$，之后照旧走老策略 $\pi$”都不亏），那么**一直走新策略 $\pi'$ 必然处处不劣于老策略 $\pi$**：$v_{\pi'}(s) \ge v_\pi(s)$！

### 三行递推证明（极其优雅！）

反复把不等式往未来展开：

$$
\begin{aligned}
v_\pi(s) &\le q_\pi\big(s, \pi'(s)\big) = \mathbb{E}\Big[R_{t+1} + \gamma v_\pi(S_{t+1}) \;\Big|\; S_t = s, A_t = \pi'(s)\Big] \\
&\le \mathbb{E}_{\pi'}\Big[R_{t+1} + \gamma q_\pi\big(S_{t+1}, \pi'(S_{t+1})\big) \;\Big|\; S_t = s\Big] \\
&= \mathbb{E}_{\pi'}\Big[R_{t+1} + \gamma R_{t+2} + \gamma^2 v_\pi(S_{t+2}) \;\Big|\; S_t = s\Big] \\
&\le \cdots \le \mathbb{E}_{\pi'}\Big[R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \cdots \;\Big|\; S_t = s\Big] = v_{\pi'}(s) \quad \blacksquare
\end{aligned}
$$

由此立得**贪心策略改进（Greedy Policy Improvement）**规则：

$$
\pi'(s) \doteq \arg\max_{a \in \mathcal{A}} q_\pi(s, a) = \arg\max_{a \in \mathcal{A}} \sum_{s', r} p(s', r \mid s, a)\big[r + \gamma v_\pi(s')\big]
$$

## 2. 策略迭代 (PI) vs 价值迭代 (VI)

把「策略评估 $E$」与「贪心策略改进 $I$」交替循环，就得到两大经典 DP 求解器：

1. **策略迭代（Policy Iteration, PI）**：
   $$
   \pi_0 \xrightarrow{\;E \text{ (跑到收敛)}\;} v_{\pi_0} \xrightarrow{\;I\;} \pi_1 \xrightarrow{\;E\;} v_{\pi_1} \xrightarrow{\;I\;} \cdots \xrightarrow{\;I\;} \pi_*
   $$
   因为有限 MDP 确定性策略总数 $|\mathcal{A}|^{|\mathcal{S}|}$ 有限，且每轮严格变好，PI 常常在 **3–6 轮外层改进**内就精确锁定全局最优 $\pi_*$！但缺点是每次内部评估 $E$ 都要扫描很多遍。
2. **价值迭代（Value Iteration, VI）**：
   既然不必要等 $v_\pi$ 算到小数点后 6 位才去改策略，干脆把评估截断成 **1 次扫描**，把 $\max_a$ 直接融进备份式——这恰好就是把 **Bellman 最优方程**变成了更新公式：
   $$
   V_{k+1}(s) \;\leftarrow\; \max_{a \in \mathcal{A}} \sum_{s', r} p(s', r \mid s, a)\Big[\, r + \gamma V_k(s') \,\Big]
   $$
   同样可证 Bellman 最优算子 $\mathcal{T}^*$ 也是 $\gamma$-压缩映射，唯一收敛于 $v_*$！

## 3. 动态规划的阿喀琉斯之踵：维度灾难（Curse of Dimensionality）

DP 如此精确优雅，为什么围棋、自动驾驶、大模型里却很少直接跑价值迭代？
1. **必须已知完整转移模型 $p(s', r \mid s, a)$**：现实物理世界和人类语言交互几乎写不出精确转移概率表；
2. **维度灾难**：单次同步扫描复杂度为 $O(|\mathcal{S}|^2 |\mathcal{A}|)$。如果一个机器人有 10 个关节，每个关节离散化成 100 档，总状态数高达 $100^{10} = 10^{20}$ —— 哪怕把全地球的显卡拼起来，连第一轮扫描都跑不完！

## 4. Python 完整价值迭代实现

```python
import numpy as np

def value_iteration(P, gamma=0.9, theta=1e-5):
    """标准价值迭代：返回最优价值 V* 与确定性最优策略 pi*"""
    n_states = len(P)
    n_actions = len(P[0])
    V = np.zeros(n_states, dtype=float)

    while True:
        delta = 0.0
        for s in range(n_states):
            q_sa = [
                sum(p * (r + (0.0 if done else gamma * V[ns])) for p, ns, r, done in P[s][a])
                for a in range(n_actions)
            ]
            best_v = max(q_sa)
            delta = max(delta, abs(best_v - V[s]))
            V[s] = best_v
        if delta < theta:
            break

    # 从收敛后的 V* 贪心提取最优策略 π*
    policy = np.zeros(n_states, dtype=int)
    for s in range(n_states):
        q_sa = [
            sum(p * (r + (0.0 if done else gamma * V[ns])) for p, ns, r, done in P[s][a])
            for a in range(n_actions)
        ]
        policy[s] = int(np.argmax(q_sa))
    return V, policy
```
