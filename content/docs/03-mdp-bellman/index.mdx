## 1. 告别单状态世界：当你的动作会改变未来

在第 2 章的老虎机赌场里，不管你刚才拉了 1 号机还是 3 号机，下一轮摆在你面前的还是那 5 台一模一样的机台——**你的动作不会改变你所处的状态**。

但真实世界的决策远比老虎机棘手得多：
- 在学生生涯里，今天选择“专注听课”虽然眼下很累（即时奖励 `-2`），但它会把你送进“掌握知识”的状态，让你在期末拿到 `+10`；
- 今天选择“刷手机摸鱼”眼下损失更小（`-1`），却会让你原地踏步甚至陷入死循环！

为了统一描述这种“动作既影响即时奖励、又驱动状态演化”的序贯世界，我们引入强化学习的数学母语——**马尔可夫决策过程（Markov Decision Process, MDP）**。

## 2. 马尔可夫性质：现在已经浓缩了全部历史

设到时刻 $t$ 为止的完整历史为 $H_t = (S_0, A_0, R_1, \dots, S_{t-1}, A_{t-1}, R_t, S_t)$。若状态 $S_t$ 满足：

$$
\mathbb{P}\big(S_{t+1} = s', R_{t+1} = r \;\big|\; S_t, A_t\big) \;=\; \mathbb{P}\big(S_{t+1} = s', R_{t+1} = r \;\big|\; H_t, A_t\big)
$$

我们就称该状态具有**马尔可夫性质（Markov Property）**——通俗地说：**“给定现在，未来与过去条件独立。”**

### ⚠️ 现实中的状态天然满足马尔可夫性吗？

往往**不满足**，但我们可以通过**状态工程**把它“改造”成马尔可夫状态：

| 场景 | 原始单帧观测 $O_t$ 为何不满足马尔可夫性？ | 工程构造马尔可夫状态 $S_t$ 的方法 |
| --- | --- | --- |
| **Atari 打砖块** | 单张像素截图看不出小球正在往左飞还是往右飞、速度有多快 | **帧堆叠（Frame Stacking）**：把最近连续 4 帧拼接成 $S_t = [O_{t-3}, O_{t-2}, O_{t-1}, O_t]$ |
| **扑克牌 / 德州扑克** | 看不见对手手里的底牌，历史下注节奏藏着信息 | **部分可观测 MDP (POMDP)**：用循环网络 (GRU/Transformer) 编码历史动作序列 |
| **大语言模型对话** | 单看最后一个词完全不知道上下文在聊什么 | 把从头到尾的**完整 Token 前缀** $[x_1, \dots, x_t]$ 整体作为当前状态 $S_t$ |

## 3. 从 MP → MRP → MDP 五元组

MDP 由五元组 $(\mathcal{S}, \mathcal{A}, \mathcal{P}, \mathcal{R}, \gamma)$ 完整定义，而其核心动力学可以用一个统一的四元联合概率分布来刻画：

$$
p(s', r \mid s, a) \doteq \mathbb{P}\big(S_{t+1} = s', R_{t+1} = r \;\big|\; S_t = s, A_t = a\big)
$$

只要掌握了 $p(s', r \mid s, a)$，任何我们关心的子量都能通过**边缘化求和**精准导出：

1. **状态转移概率**：
   $$
   p(s' \mid s, a) = \sum_{r \in \mathcal{R}} p(s', r \mid s, a)
   $$
2. **状态-动作期望奖励**：
   $$
   r(s, a) \doteq \mathbb{E}\big[R_{t+1} \mid S_t = s, A_t = a\big] = \sum_{r \in \mathcal{R}} r \sum_{s' \in \mathcal{S}} p(s', r \mid s, a)
   $$

## 4. Python 最小 MDP 转移与采样实现

```python
import numpy as np

# 用字典精确表示有限 MDP 的四元动力学 p(s', r | s, a)
# 格式: P[state][action] = [(prob, next_state, reward, done), ...]
STUDENT_MDP = {
    "C1": {
        "study": [(0.8, "C2", -2.0, False), (0.2, "C1", -2.0, False)],
        "relax": [(0.9, "Relax", -1.0, False), (0.1, "C1", -1.0, False)],
    },
    "Relax": {
        "relax": [(0.85, "Relax", -1.0, False), (0.15, "C1", -1.0, False)],
        "back":  [(1.0, "C1", 0.0, False)],
    },
    "C2": {
        "study": [(0.8, "Pass", -2.0, False), (0.2, "C1", -2.0, False)],
        "sleep": [(1.0, "Sleep", 0.0, True)],
    },
    "Pass": {
        "celebrate": [(1.0, "Sleep", +10.0, True)],
    },
}

def sample_episode(mdp, policy, gamma=0.9, seed=42):
    rng = np.random.default_rng(seed)
    state, G, discount = "C1", 0.0, 1.0
    path = [state]
    while state != "Sleep":
        action = policy(state)
        transitions = mdp[state][action]
        probs = [tr[0] for tr in transitions]
        _, next_state, reward, done = transitions[rng.choice(len(transitions), p=probs)]
        G += discount * reward
        discount *= gamma
        state = next_state
        path.append(state)
        if done:
            break
    return path, G

path, G = sample_episode(STUDENT_MDP, lambda s: list(STUDENT_MDP[s].keys())[0])
print("采样轨迹:", " → ".join(path), "| 折扣回报 G₀ =", round(G, 2))
```
