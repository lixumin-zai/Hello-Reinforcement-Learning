智能体的目标是“最大化未来累积奖励”。那么，从时刻 $t$ 往后的奖励序列 $R_{t+1}, R_{t+2}, R_{t+3}, \dots$ 应该怎样加总成一个标量呢？这个加总后的随机变量就叫做**回报（Return）**，记作 $G_t$。

---

## 1. 分幕式任务与持续式任务

- **分幕式任务（Episodic Tasks）**：交互会在某个有限步 $T$ 自然到达**终止状态（Terminal State）**，例如一盘棋、一局游戏。此时可以直接求和：
  $$
  G_t = R_{t+1} + R_{t+2} + \cdots + R_T
  $$
- **持续式任务（Continuing Tasks）**：交互没有终点（$T = \infty$），例如数据中心温控或股票自动做市。若直接将无穷项相加，$\sum_{k=0}^\infty R_{t+k+1}$ 很容易发散为 $\infty$。

为此，我们引入**折扣因子（Discount Factor）** $\gamma \in [0, 1]$，统一定义**折扣回报**：

$$
G_t \doteq R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \cdots = \sum_{k=0}^{\infty} \gamma^k R_{t+k+1}
$$

---

## 2. 回报的核心递归关系

把上式从第二项起提取公因式 $\gamma$，立即得到贯穿整个强化学习的递归恒等式：

$$
\begin{aligned}
G_t &= R_{t+1} + \gamma \big(R_{t+2} + \gamma R_{t+3} + \gamma^2 R_{t+4} + \cdots\big) \\
    &= R_{t+1} + \gamma G_{t+1}
\end{aligned}
$$

## 3. 为什么要折扣？三种直观解释

1. **数学收敛性**：只要每步奖励有界 $|R_t| \le R_{\max}$ 且 $\gamma < 1$，无穷级数绝对收敛：
   $$
   |G_t| \le R_{\max}\sum_{k=0}^\infty \gamma^k = \frac{R_{\max}}{1 - \gamma}
   $$
2. **未来的不确定性**：你可以把 $\gamma$ 看作交互在下一步“继续存活而不意外终止”的概率。
3. **有效视野（Effective Horizon）**：因为 $\sum_{k=0}^\infty \gamma^k = \frac{1}{1-\gamma}$，折扣因子为 $\gamma$ 的智能体大约等效于向前看 $\frac{1}{1-\gamma}$ 步（例如 $\gamma = 0.9 \Rightarrow 10$ 步，$\gamma = 0.99 \Rightarrow 100$ 步）。
