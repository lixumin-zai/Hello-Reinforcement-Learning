## 核心知识点

- 状态 = 历史上下文前缀、动作 = 下一个词表 Token、转移 = 确定性拼接
- 序列级稀疏奖励与超长动作空间 |V| ≈ 10⁵ 的挑战
- 参考策略 π_ref 与 KL 惩罚项防止语言退化
- 大模型后训练全景图：SFT → 偏好对齐 → 可验证强化推理
