## 1. 撕掉上帝地图：如果不知道 $p(s', r \mid s, a)$ 怎么办？

思考一个经典问题——**21 点（Blackjack）**：你和庄家各发两张牌，庄家有一张明牌和一张暗牌。你要决定继续**要牌（HIT）**还是**停牌（STICK）**，目标是手牌点数尽可能接近 21 且不爆牌。

为什么不用第 4 章的动态规划直接解 21 点？算算就头大了：你要手工推导在庄家明牌为 6、你手握软 18 的条件下，停牌后庄家连续补 1 张、2 张、3 张、4 张牌最终落在 17/18/19/20/21 或爆牌的精确条件概率矩阵——极其繁琐且极易算错！

但让计算机**直接按规则打 10 万局 21 点**却只需要 50 行代码、不到 0.1 秒！这就是**蒙特卡洛方法（Monte Carlo, MC）**的朴素哲学：

> **既然 $v_\pi(s) = \mathbb{E}_\pi[G_t \mid S_t = s]$ 是回报的数学期望，只要遵循策略 $\pi$ 反复玩很多完整回合，把每次经过状态 $s$ 后实际拿到的完整回报 $G_t$ 取算术平均，由大数定律它必定收敛到真实价值 $v_\pi(s)$！**

## 3. First-Visit MC vs Every-Visit MC 预测算法

如果一条回合轨迹里，同一个状态 $s$ 被智能体多次经过，应该算一次还是算多次？

1. **首次访问蒙特卡洛（First-Visit MC）**：每回合中，**只对状态 $s$ 第一次出现后的回报 $G_t$** 计入均值。各回合的回报相互独立同分布，因此是 $v_\pi(s)$ 的**严格无偏估计**，标准差按 $1/\sqrt{N(s)}$ 下降；
2. **每次访问蒙特卡洛（Every-Visit MC）**：每回合中，**状态 $s$ 每出现一次**都把对应的 $G_t$ 计入均值。在工程上省去了维护“本回合已访问集合”的开销，虽然单次有微小相关性，但同样以概率 $1$ 渐近收敛至 $v_\pi(s)$。

### 高效的 $O(T)$ 反向递推算法

为了避免对每个时刻都从头求和（$O(T^2)$），标准做法是**等整局结束后从 $t = T - 1$ 倒序回溯至 $t = 0$**：

$$
G \;\leftarrow\; \gamma \, G + R_{t+1}, \qquad V(S_t) \;\leftarrow\; V(S_t) + \frac{1}{N(S_t)}\big(G - V(S_t)\big)
$$

## 4. 蒙特卡洛相比动态规划的三大惊艳特性

1. **完全无模型（Model-Free）**：只要能仿真或与真实环境交互，无需任何转移概率公式；
2. **不自举（No Bootstrapping）**：每个状态的价值估计只依赖自己身后真实走完的回报 $G_t$，**不依赖其他状态的估计值**！因此它天然零偏差，且在部分非马尔可夫环境中抗干扰能力更强；
3. **局部评估复杂度与总状态数无关**：如果你只关心某一个特定状态 $s_0$ 的价值（例如棋局当前的唯一盘面），只需从 $s_0$ 出发采样几千条轨迹即可，完全不用像 DP 那样扫描全宇宙所有状态！

## 5. 可运行 Python First-Visit MC 预测代码

```python
from collections import defaultdict

def first_visit_mc_prediction(env, policy, episodes=10000, gamma=1.0):
    V = defaultdict(float)
    N = defaultdict(int)

    for _ in range(episodes):
        # 1. 正向采样一条完整回合
        state, _ = env.reset()
        episode, done = [], False
        while not done:
            action = policy(state)
            next_state, reward, term, trunc, _ = env.step(action)
            episode.append((state, action, reward))
            state, done = next_state, term or trunc

        # 2. 反向时间倒带计算 G_t，仅更新首次出现的状态
        G = 0.0
        visited = set()
        first_idx = {}
        for idx, (s, _, _) in enumerate(episode):
            if s not in first_idx:
                first_idx[s] = idx

        for t in range(len(episode) - 1, -1, -1):
            s, _, r = episode[t]
            G = gamma * G + r
            if t == first_idx[s]:            # 仅在首次访问位置更新
                N[s] += 1
                V[s] += (G - V[s]) / N[s]
    return V
```
