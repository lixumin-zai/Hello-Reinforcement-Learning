## 1. 无模型控制的第一个转折：必须从 $V(s)$ 转向 $Q(s, a)$

在 4.2 节的动态规划里，只要算出状态价值 $V(s)$，我们就可以通过前瞻一步算出最优策略：
$$
\pi'(s) = \arg\max_a \sum_{s', r} p(s', r \mid s, a)\big[r + \gamma V(s')\big]
$$
但现在我们**没有环境模型 $p(s', r \mid s, a)$**！拿着一张 $V(s)$ 表，你根本算不出选哪个动作会去哪个 $s'$。

解决办法在第 3 章早已埋好伏笔：**直接用蒙特卡洛估计动作价值函数 $Q(s, a)$**！一旦有了 $Q(s, a)$，策略改进就彻底脱离环境模型：

$$
\pi'(s) = \arg\max_{a \in \mathcal{A}} Q(s, a)
$$

## 2. 探索困境再现：探索性起点 vs On-Policy $\varepsilon$-Soft 控制

如果每次改进都把策略变成**确定性贪心** $\pi(s) = \arg\max_a Q(s, a)$，很快所有回合都只走同一个动作，其他动作再也不会被采样到——GPI 的评估环节因为看不到未尝试动作的真实回报而彻底停摆！

教科书给出两条出路：

1. **探索性起点（Exploring Starts, ES）**：强行要求每一局的初始状态-动作对 $(S_0, A_0)$ 以非零概率覆盖所有可能组合。在 21 点仿真器里容易做到，但在真实机器人或游戏里你不可能把汽车凭空瞬移到悬崖半空中开局；
2. **在策略 $\varepsilon$-Soft 控制（On-Policy $\varepsilon$-Soft MC Control）**：放弃寻找确定性策略，强制策略对任意状态下的所有动作都保留至少 $\frac{\varepsilon}{|\mathcal{A}|}$ 的探索概率：
   $$
   \pi(a \mid s) = \begin{cases}
   1 - \varepsilon + \dfrac{\varepsilon}{|\mathcal{A}|}, & \text{若 } a = \arg\max_{a'} Q(s, a') \\[8pt]
   \dfrac{\varepsilon}{|\mathcal{A}|}, & \text{其他动作}
   \end{cases}
   $$

### GLIE 条件：如何既充分探索又收敛到真正最优 $\pi_*$？

如果在训练过程中让 $\varepsilon_k$ 随回合数 $k$ 缓慢衰减（例如 $\varepsilon_k = \frac{1}{k}$），使其满足 **GLIE（Greedy in the Limit with Infinite Exploration）** 两条黄金性质：
1. 所有状态-动作对被访问无穷多次：$\lim_{k \to \infty} N_k(s, a) = \infty$；
2. 策略在极限上收敛为确定性贪心策略：$\lim_{k \to \infty} \pi_k(a \mid s) = \mathbb{I}\big(a = \arg\max_{a'} Q_k(s, a')\big)$。

那么 On-Policy 蒙特卡洛控制保证以概率 $1$ 收敛至最优动作价值 $q_*$ 与最优策略 $\pi_*$！

## 4. 完整可运行 Python 21 点 GLIE MC Control 代码

```python
import numpy as np
from collections import defaultdict

def mc_control_glie(env, episodes=50000, gamma=1.0):
    n_actions = env.action_space.n
    Q = defaultdict(lambda: np.zeros(n_actions))
    N = defaultdict(lambda: np.zeros(n_actions))

    for k in range(1, episodes + 1):
        eps = max(0.02, 1.0 / (1.0 + k / 500.0))      # GLIE 衰减探索率
        state, _ = env.reset()
        episode, done = [], False

        while not done:
            if np.random.rand() < eps:
                action = np.random.randint(n_actions)
            else:
                action = int(np.argmax(Q[state]))
            next_state, reward, term, trunc, _ = env.step(action)
            episode.append((state, action, reward))
            state, done = next_state, term or trunc

        G = 0.0
        for s, a, r in reversed(episode):
            G = gamma * G + r
            N[s][a] += 1
            Q[s][a] += (G - Q[s][a]) / N[s][a]        # Every-Visit 增量更新

    policy = {s: int(np.argmax(q)) for s, q in Q.items()}
    return Q, policy
```
