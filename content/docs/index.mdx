## 这是一本什么样的强化学习教程？

强化学习（Reinforcement Learning, RL）不是一堆可以背诵的 API 字典，而是一门关于**序贯决策、试错探索与长期权衡**的数学与算法学科。

为了让抽象的 Bellman 方程、重要性采样、致命三元组、PPO 截断与 GRPO 组相对优势真正变成你的直觉，本教程按 **4 个难度阶梯、10 章 34 节**编排，每一节都将四种载体融合在一起：

| 学习维度 | 我们怎么做 | 你将收获什么 |
| --- | --- | --- |
| 🎮 **完整小游戏与物理仿真** | 霓虹老虎机人机争霸赛、21 点赌场、悬崖双智能体竞速、键盘驾驶山地车、平衡倒立摆、井字棋 MCTS 实时搜索树 | 先亲手“玩崩”感受痛点，再看 RL 算法如何优雅破局 |
| 📐 **分步数学推导 + 手算算例** | 拒绝直接甩结论：把增量均值、Bellman 递归、策略梯度 log-derivative、DPO 闭式解一步步推给你看 | 真正看懂公式里每一个符号与负号存在的理由 |
| 🎬 **多世界观 Remotion 动效** | 复古街机、3Blue1Brown 数学黑板、等高线水波、绿绒牌桌时间倒带、物理弹簧、工程遥测、AI Token 流 | 逐帧看清算法内部的动态因果，支持暂停/拖帧/倍速 |
| 💻 **可运行 Python / PyTorch 代码** | 核心算法全部提供干净、自包含的 Python 实现，并附高频误区剖析与交互自测题 | 学完就能直接在本地复现与调参 |
