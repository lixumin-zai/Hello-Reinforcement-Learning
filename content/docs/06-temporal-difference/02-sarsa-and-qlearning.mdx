## 1. 一字之差，两种截然不同的性格

把 6.1 节的 TD(0) 从状态价值 $V(s)$ 推广到动作价值 $Q(s, a)$，就诞生了表格无模型控制史上最著名的“双子星”——**SARSA** 与 **Q-learning**。仔细对比它们更新公式里**仅仅不同的一处**：

### ① SARSA（在策略 On-Policy TD 控制）

智能体用当前含探索噪声的策略（如 $\varepsilon$-greedy）实际采样出五元组 $(S_t, A_t, R_{t+1}, S_{t+1}, A_{t+1})$，并直接用**下一步真正要执行的动作 $A_{t+1}$** 来构造自举目标：

$$
Q(S_t, A_t) \;\leftarrow\; Q(S_t, A_t) + \alpha\Big[\, R_{t+1} + \gamma \, \underbrace{Q(S_{t+1}, A_{t+1})}_{\text{下一步实际含噪动作}} - Q(S_t, A_t) \,\Big]
$$

### ② Q-learning（离策略 Off-Policy TD 控制，Watkins 1989）

不管下一步实际因为 $\varepsilon$ 探索走了什么歪路，Q-learning 永远假定从 $S_{t+1}$ 开始执行**最完美的贪心动作**，直接取 $\max_{a'} Q(S_{t+1}, a')$ 作为自举目标：

$$
Q(S_t, A_t) \;\leftarrow\; Q(S_t, A_t) + \alpha\Big[\, R_{t+1} + \gamma \, \underbrace{\max_{a' \in \mathcal{A}} Q(S_{t+1}, a')}_{\text{理想最优动作（无需重要性采样！）}} - Q(S_t, A_t) \,\Big]
$$

> **为何 Q-learning 是离策略却不需要 5.3 节那种可怕的重要性采样比 $\rho$？**  
> 因为在单步 Bellman 最优备份里，$Q(S_t, A_t)$ 的条件已经固定了当前动作 $A_t$，而下一刻我们直接解析地取了 $\max_{a'} Q(S_{t+1}, a')$（而不是对后续整条随机轨迹求均值），彻底绕开了连乘 $\frac{\pi}{b}$ 的方差爆炸！

## 3. Expected SARSA：优雅统一两者的低方差升级版

SARSA 在更新时把 $Q(S_{t+1}, A_{t+1})$ 押注在**单次随机抽样的 $A_{t+1}$** 上，引入了额外的动作选择方差。既然当前策略 $\pi(a'\mid S_{t+1})$ 就在我们手里，何不直接对所有可能动作求解析期望？

$$
Q(S_t, A_t) \;\leftarrow\; Q(S_t, A_t) + \alpha\left[\, R_{t+1} + \gamma \sum_{a' \in \mathcal{A}} \pi(a' \mid S_{t+1})\, Q(S_{t+1}, a') - Q(S_t, A_t) \,\right]
$$

- 当 $\pi$ 取当前的 $\varepsilon$-greedy 策略时，Expected SARSA 是在策略且**方差严格低于 SARSA**（允许用更大的学习率 $\alpha$ 而不震荡）；
- 当 $\pi$ 取确定性贪心策略 $\pi(a'\mid s') = \mathbb{I}(a' = \arg\max Q)$ 时，求和瞬间退化为 $\max_{a'} Q(S_{t+1}, a')$ —— **Q-learning 其实就是 Expected SARSA 的一个特例！**

## 4. 可运行 Python 完整代码（一套循环支持三种算法）

```python
import numpy as np

def train_td_control(env, algo="q_learning", episodes=500, alpha=0.5, gamma=1.0, eps=0.1, seed=42):
    rng = np.random.default_rng(seed)
    nS, nA = env.observation_space.n, env.action_space.n
    Q = np.zeros((nS, nA))

    def eps_greedy(s):
        return int(rng.integers(nA)) if rng.random() < eps else int(np.argmax(Q[s]))

    returns = []
    for _ in range(episodes):
        s, _ = env.reset()
        a = eps_greedy(s)
        ep_ret, done = 0.0, False

        while not done:
            ns, r, term, trunc, _ = env.step(a)
            done = term or trunc
            na = eps_greedy(ns)

            if done:
                bootstrap = 0.0
            elif algo == "q_learning":
                bootstrap = float(np.max(Q[ns]))
            elif algo == "sarsa":
                bootstrap = float(Q[ns, na])
            else:  # expected_sarsa
                best = int(np.argmax(Q[ns]))
                probs = np.full(nA, eps / nA)
                probs[best] += 1.0 - eps
                bootstrap = float(np.dot(probs, Q[ns]))

            Q[s, a] += alpha * (r + gamma * bootstrap - Q[s, a])
            ep_ret += r
            s, a = ns, na
        returns.append(ep_ret)
    return Q, returns
```
